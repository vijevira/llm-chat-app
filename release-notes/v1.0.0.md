# Omni Chat v1.0.0 - Production Release 🚀

Welcome to the initial production release of **Omni Chat** (v1.0.0), a high-performance, universal AI assistant interface featuring access to 500+ LLM models, full-featured creative media generation (Images, Videos, Music, Documents), custom workspaces & prompt studio, and cross-device cloud sync.

---

### ✨ Key Features & Capabilities

#### 1. 💬 Modern Gemini-Style Chatbox & Creative Tools
- **Single `+` Tools Popover**: Replaced cluttered buttons with a single left-side `+` button that rotates 45° to `✕` when open, presenting a floating popover menu:
  - **Upload Files**: Direct attachment support for PDFs, Word DOCX, text files, code scripts, CSV, and JSON.
  - **Upload Images**: Instant upload and thumbnail preview for photos, screenshots, and visual assets.
  - **Creative Tools (After Divider)**: Quick switches for **Create Image**, **Create Video**, and **Create Music**.
- **Voice Dictation (Mic Input)**: Right-side microphone button with live speech-to-text dictation via the Web Speech API and pulsing visual wave animation while listening.
- **Inline Model Selector Pill**: Second-from-right chatbox pill (`✨ gpt-4o-mini ▾`) displaying the active model and opening the 500+ model catalog directly from the input row.
- **Active Mode Indicators**: Visual pill tags indicating when Image, Video, or Music creation modes are active, with one-click `✕` dismissal.
- **Clipboard & Drag-and-Drop**: Paste images or documents directly from your clipboard (<kbd>Cmd+V</kbd> / <kbd>Ctrl+V</kbd>) or drag files anywhere onto the input container.

#### 2. 🎨 Multimodal AI Generation Studio
- **AI Image Generation**: Built-in `puter.ai.txt2img` generation supporting descriptive prompts, `/image` slash commands, client-side downscaling optimization, and one-click image downloads.
- **AI Video Generation**: High-fidelity motion clip generation via `puter.ai.txt2vid` (Wan 2.1 model) featuring real-time rendering status spinners and looping video playback cards with direct MP4 downloads.
- **AI Music & Audio Synthesis**: Interactive Web Audio API synthesizer supporting musical prompts (`/music`, "compose a beat", "chill lofi soundtrack"). Features dynamic BPM and genre detection (Lofi, Synthwave, Cinematic, Electronic), melodic progressions, and animated visualizer bars.
- **Automated Document Export**: Intelligent intent detection for PDF and Word DOCX requests. Generates beautifully formatted markdown and compiles it into instant downloadable `.pdf` and `.docx` files.

#### 3. 🧠 500+ AI Models Catalog & Provider Hub
- **Zero API Key Required**: Free, instant access to leading foundation models powered by Puter.js:
  - **Google**: Gemini 2.5 Flash, Gemini 2.5 Pro, Gemini 2.0 Flash, Gemma 2.
  - **OpenAI**: GPT-4o, GPT-4o Mini, o1, o3-mini.
  - **Anthropic**: Claude 3.5 Sonnet, Claude 3.5 Haiku, Claude 3 Opus.
  - **DeepSeek**: DeepSeek R1 Reasoning, DeepSeek V3.
  - **Meta, Mistral, xAI**: Llama 3.3 70B, Codestral, Mistral Large, Grok 2.
- **Intelligent Catalog UI**: Real-time search, family provider filtering tabs, context window indicators, and reasoning badges.

#### 4. ⚡ Custom Projects & In-Window Studio
- **Isolated AI Workspaces**: Create dedicated project environments with tailored system instructions:
  - **Intent & Core Role**: Defines the persona and objective of the assistant.
  - **Background Context**: Codebase structure, domain vocabulary, and conventions.
  - **Output Constraints**: Formatting rules, code syntax, and strict response guidelines.
- **Knowledge Base Document Grounding**: Drag-and-drop document grounding with real-time token count estimation.
- **In-Window Project Studio**: Comprehensive editor with live side-by-side prompt testing preview pane.
- **Grouped Sidebar Hierarchy**: Projects list with expandable nested conversation trees and quick-add session shortcuts.

#### 5. 🌐 Puter Cloud & Cross-Device Storage Synchronization
- **Dual-Tier Storage Architecture**: Automatic synchronization between browser `localStorage`, Puter Cloud Key-Value store, and Puter Filesystem (`/Documents/OmniChat/`).
- **Cross-Device Sync**: Seamless session and workspace continuity between `localhost` and production deployment domains (`chat.vijevira.in`).
- **User Identity & Profiles**: Support for custom display names, `@username` handles, avatar initials, and Puter account management.
- **Data Portability**: Full JSON export and restore capabilities for complete chat histories.

#### 6. ☁️ Cloudflare Workers Edge Architecture
- **Edge Deployment**: Lightweight, global distribution using Cloudflare Workers and static asset binding.
- **Zero-Latency Serving**: Streaming responses with graceful offline fallback and local cache preservation.

### 📦 Deployment & Setup

```bash
# Clone the repository
git clone https://github.com/vijevira/llm-chat-app.git
cd llm-chat-app

# Install dependencies
npm install

# Start local development server with Wrangler
npm run dev

# Deploy to Cloudflare Workers
npm run deploy
```
