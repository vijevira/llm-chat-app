# Omni Chat v1.1.0 - Interactive Artifacts, Tool Plugins & Custom Apps Hub 🚀

We are excited to release **Omni Chat v1.1.0**, a major evolution transforming Omni Chat from a conversation interface into a complete generative development platform. This release introduces interactive live artifacts, an intelligent tool plugins engine (Web Search Grounding and in-browser JS code runner), a custom AI apps directory, and key mobile stability improvements.

---

### ✨ Key Highlights & Features

#### 1. 🚀 Pillar 1: Interactive Live Artifacts & Web App Hosting
- **Split-Screen Live Artifact Viewer**: Run and preview generated web code (HTML, CSS, JavaScript, Tailwind, SVG, and web apps) directly in a dedicated side-by-side or mobile-friendly split panel.
- **Runnable Code Block Integration**: Automated detection of complete frontend applications in AI responses with an instant **"▶ Run App / Preview"** button.
- **Code & Preview Toggle**: Switch seamlessly between the source code view and live interactive rendering.
- **Mobile Viewport Switcher**: Toggle between Desktop (100% responsive) and Mobile (375px mobile device emulator) modes with a single click.
- **1-Click Puter Cloud Hosting**: Host any artifact publicly on the web (`https://<slug>.puter.site`) with zero configuration, automatic slug generation, and live URL sharing.

#### 2. 🧩 Pillar 2: Intelligent Tool Plugins Engine
- **Interactive Tool Pill Composer**: Floating quick-toggle pills positioned directly above the input box:
  - 🌐 **Web Search**: Real-time web grounding with DuckDuckGo integration on Cloudflare Workers (`/api/search`). Automatically extracts fresh snippets and renders clickable citation tags (`[1]`, `[2]`).
  - ⚡ **Code Runner**: In-browser client-side JavaScript execution sandbox. Run code snippets safely via `/run <code>` or code cards, capturing `console.log` output and return values.
  - 🧩 **Plugins Hub**: Unified modal to view, enable, and manage active system tools.

#### 3. 📱 Pillar 3: Custom AI Apps Hub & Guided Creator
- **Explore Apps Catalog**: Browse a curated showcase of 6 frontier specialized applications:
  1. *Modern Landing Page Architect* (Front-end design & responsive layout generation)
  2. *Regex Wizard & Explainer* (Pattern generation, unit test cases, and breakdown)
  3. *TypeScript API Client Forge* (Type-safe schemas, interfaces, and fetch wrappers)
  4. *CSS Micro-Interactions Studio* (Keyframes, hover transitions, and SVG effects)
  5. *SQL Query Optimizer & Visualizer* (Query tuning, indexing suggestions, and schema plans)
  6. *System Prompt Refiner & Evaluator* (Few-shot prompting, guardrails, and role engineering)
- **Guided Visual App Creator**: Create custom apps with custom name, emoji icon, system instructions, creativity temperature, default model, and pre-bundled tools.
- **Deep-Linkable URL Slugs**: Launch and share any custom app directly via URL query parameters (`?app=<id>`).
- **Cloud & Local Persistence**: Custom apps automatically sync to Puter Cloud Key-Value storage (`omni_chat_custom_apps`) and local browser cache.

#### 4. 🛠️ Critical Bug Fixes & UX Polish
- **1-Click Platform Navigation**: Added prominent **⚡ Web Sandbox**, **🧩 Plugins**, and **🧭 Explore Apps** quick buttons to both the desktop topbar and sidebar navigation for instant access.
- **Chatbox Layout Preservation**: Fixed layout collapsing when closing/cancelling the Custom AI App Studio by strictly enforcing block display on the input wrapper.
- **Puter SDK Header Sanitizer**: Implemented a transparent client-side request sanitizer that strips forbidden headers (`Origin`, `Referer`) before native fetch, completely silencing `Refused to set unsafe header "Origin"` browser console warnings.
- **Mobile Streaming Flicker**: Resolved DOM repainting issues during active LLM token streaming by implementing a microtask-buffered rendering queue.
- **Mobile Keyboard Newline Behavior**: The <kbd>Enter</kbd> key on mobile keyboards now correctly inserts a new line; message submission is triggered strictly via the Send button or <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>Enter</kbd>.
- **Sidebar Initial State on Mobile**: Sidebar is now closed by default on viewports `< 768px` for a clean, unobstructed chat experience upon loading.
- **Settings & Profile Modal Layout**: Eliminated unintended header scrolling; tabs and titles remain fixed while modal bodies scroll smoothly.
- **Resolved Puter SDK Syntax Notice**: Fixed an unclosed block brace in `chat.js` causing parsing errors on remote CDNs.
