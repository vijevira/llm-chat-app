# Omni Chat v1.2.0 - Dedicated Web App Sandbox Studio, Plugins Marketplace & Community Apps 🚀

We are thrilled to release **Omni Chat v1.2.0**, introducing a dedicated two-part Web App Sandbox Studio (v0/Bolt style), an extensive 8-Plugin Marketplace with one-click installation, deep GitHub repository importing, and interactive Community AI Apps.

---

### ✨ Key Features & Enhancements

#### 1. ⚡ Dedicated Web App Sandbox Studio (Split Chat/Codebase & Live Preview)
- **Two-Part Workspace Layout**:
  - **Left Part (Chat & Codebase)**:
    - **AI Chat Tab**: Interactive conversation with the AI coder. Users describe what app they want to build, and iterate in real-time (*"Add dark mode"*, *"Add sound effects"*, *"Add search bar"*).
    - **Codebase & Files Tab**: Inspect generated files (`index.html`, `style.css`, `script.js` or all-in-one code) with line counts, syntax styling, and a 1-click **Copy Code** button.
  - **Right Part (Live Preview & Hosting)**:
    - **Real-Time Sandboxed Preview**: Hot-reloads running applications upon generation and after every iteration.
    - **1-Click Puter Hosting / Publish**: Instant deployment to live web hosting (`https://<subdomain>.puter.site`) with zero configuration and live URL copying.
    - **Responsive Viewport Toggles**: Toggle between Desktop (100%) and Mobile (375px) device simulation.
    - **Single File Download**: Export complete standalone application as `index.html`.
- **Clean Generative Initial State**:
  - **No Default App**: Opening the Sandbox Studio greets users with a clean app builder prompt interface and inspiration chips (*Breakout Arcade*, *Pomodoro Timer*, *Kanban Workspace*, *Financial Dashboard*, *Markdown Notes*, *Drum Machine*) or GitHub import.

#### 2. ⚡ Live App Building & Compiling Feedback Pipeline
- **Real-Time Step-by-Step Progress in Chat**:
  - Automatically transitions to active chat as soon as an app is requested—no blank or unresponsive states.
  - Interactive status card (`.sandbox-building-card`) with a pulsing gradient indicator and 5-step compilation pipeline:
    - 🔍 **Architecture Planning**: Analyzes the prompt and scaffolds application components.
    - 🏗️ **HTML Structure**: Generates semantic markup (`index.html`).
    - 🎨 **Styles & Theme**: Implements responsive CSS / Tailwind styling (`style.css`).
    - ⚡ **Interactive Logic**: Hooks up state management, DOM events, and algorithms (`script.js`).
    - 🚀 **Runtime Compilation**: Packages assets into the live sandbox iframe.
- **Live Code Stream Ticker**:
  - Live terminal-style ticker (`.sandbox-live-stream-log`) streaming code and AI thoughts as they generate.
- **Dynamic File Generation Badges**:
  - Highlights `📄 index.html`, `🎨 style.css`, and `⚡ script.js` chips as each code section is encountered.
- **Live Preview Compilation Overlay**:
  - Pulsing compilation ring overlay (`.sandbox-preview-compiling-overlay`) covering the preview pane during generation and hot-reload iterations.
- **Hot-Reload Iterations**:
  - The same live streaming feedback card accompanies prompt iterations (e.g. *"Add high score counter"*, *"Add dark mode"*), updating code seamlessly without blanking out the view.

#### 3. 🕒 Persistent Web App Build History
- **Searchable App History Drawer**:
  - Topbar **History** trigger with real-time app count badge (`🕐 History (4)`).
  - Search filter input to find past builds by app title or prompt description.
  - History cards displaying app title, prompt excerpt, relative timestamp (*"5 mins ago"*, *"Oct 18"*), file/line counts, and actions:
    - **Open App**: Instantly restores the codebase, chat iterations, and live iframe preview.
    - **Export**: Opens the export modal for any historical build.
    - **Delete**: Removes individual builds from history.
    - **Clear All**: Purges history with safety confirmation.
- **Recent Builds on Initial Standby Screen**:
  - Displays recent build chips directly on the builder landing screen so users can quickly pick up where they left off.
- **Cross-Device Cloud Sync**:
  - Automatically persists to browser `localStorage` and syncs to Puter Cloud KV store when signed in.

#### 4. 📦 Complete Codebase Export System
- **Multi-File Project ZIP Archive**:
  - Powered by client-side JSZip.
  - Generates clean separated project structure:
    - `index.html`: Clean HTML linking external stylesheet and script.
    - `style.css`: Extracted CSS styles.
    - `script.js`: Extracted JavaScript logic and event handlers.
    - `README.md`: Project description, architecture overview, and local launch instructions (`npx serve .`).
    - `package.json`: Ready-to-run development manifest.
- **Standalone HTML Download**: Self-contained single-file bundle ready to run offline.
- **CodePen 1-Click Playground**: Export directly to CodePen via prefill API for instant web sharing and testing.
- **Quick Copy Individual Parts**: 1-click clipboard copy for HTML, CSS, JavaScript, or all-in-one code.

#### 5. ✏️ Interactive Manual Code Editor (Live Hot-Reload)
- **Direct In-Browser Code Editing**:
  - Tab 2 (*Codebase & Files*) upgraded from read-only display to an interactive code editor with line gutter numbers.
  - Edit across tabs: `📦 All-in-One Code`, `📄 index.html`, `🎨 style.css`, and `⚡ script.js`.
  - Bidirectional sync merges edits back into the master document seamlessly.
- **▶ Run Live & Hot-Reload (Ctrl+S / ⌘S)**:
  - Instant compilation into iframe sandbox without waiting for AI.
  - Visual status pill: `Ready`, `● Unsaved (⌘S)`, `✓ Saved & Running`.
  - Keyboard shortcuts: `Tab` for 2-space indentation, `Ctrl+S` / `Cmd+S` / `Ctrl+Enter` to run live.
- **↺ Revert to AI Baseline**: 1-click revert to original AI-generated code if experimental manual changes need to be undone.

#### 6. 🧩 Intelligent Plugins Marketplace
- **8 Autonomous Installable Plugins**:
  1. 🌐 **Live Web Search Grounding**: Real-time web facts, news, and citation chips via DuckDuckGo.
  2. ⚡ **JavaScript Code Runner**: Client-side execution sandbox for math, algorithms, and transformations.
  3. 🐙 **GitHub Repo & Code Explorer**: Inspect public repositories, view file trees, and load code into the Web Sandbox.
  4. 📊 **Chart & Data Visualizer**: Visualizes structured datasets and matrices using interactive Chart.js charts.
  5. 🧮 **LaTeX & Scientific Math Solver**: Step-by-step mathematical reasoning formatted with KaTeX.
  6. 🎨 **Tailwind & UI Component Studio**: Generates production-ready Tailwind CSS and glassmorphic components.
  7. 🔍 **SEO & Web Meta Auditor**: Audits web pages, Open Graph tags, and generates schema.org JSON-LD.
  8. 📄 **Document & PDF Deep Inspector**: Structural analysis, summary extraction, and clause extraction.
- **Category Filter Tabs**: Filter by `All (8)`, `Installed`, `Developer`, `Research & Web`, and `Analytics`.
- **State Persistence**: Active toggles and installation statuses persist across browser refreshes and sync to Puter Cloud Key-Value store.

#### 7. 🧭 Community Custom AI Apps Catalog
- **Explore Button & Shortcut**: Seamlessly browse, search, and clone pre-built frontier AI persona templates (Coding, Analysis, Writing, Research).
- **Accessible via Header & Sidebar**: One-click opening from the sidebar platform navigation or the Custom Apps section.

#### 8. 🛠️ Critical Bug Fixes
- **Resolved Unclosed Modal Tag Bug**: Fixed missing closing tags in `#settings-modal` that previously caused `#plugins-modal` and `#explore-apps-modal` to be trapped as hidden child elements of an inactive overlay.
- **Resolved `projectModalFileCount` ReferenceError**: Fixed an undeclared identifier causing custom app creation to fail.
- **Enhanced Modal Transitions**: Replaced display conflicts with smooth CSS opacity transitions and pointer event handling.
